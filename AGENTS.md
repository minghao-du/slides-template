# Project Intent

This repository is Minghao's personal slides template for creating and reusing presentation designs. It provides a consistent starting point for personal slide decks, with reusable themes, layouts, styles, and examples.

Prioritize changes that improve personal authoring convenience, visual consistency, and reuse across presentations. Keep reusable template elements separate from presentation-specific content, and follow the owner's design preferences when evolving the template.

# General Repository Rules

The following rules must be strictly adhered to across the repository:

- **Language Policy**:
  - **User Interaction**: Always communicate and converse with the user in **Chinese** (`对话用中文`).
  - **Repository Deliverables & Artifacts**: All repository documentation, README files, stage receipts, docstrings, CLI help strings, and code comments must be written in **English** (`所有的文档落地，都要英文`), unless strictly required for raw domain data matching (e.g. historical Chinese bird common names in baseline tables).
